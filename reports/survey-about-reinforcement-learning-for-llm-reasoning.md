# Survey of Reinforcement Learning for LLM Reasoning

## TL;DR
- Reinforcement learning (RL) enhances LLM reasoning by treating multi-step reasoning as a sequential decision process with verifiable rewards, reducing reliance on human feedback [1][2].
- Main approaches include PPO-based RLHF, critic-free methods like GRPO and RLOO, Direct Preference Optimization (DPO), tree-search strategies, and exploration-focused techniques such as ARM and competence-difficulty alignment [3][4][5][6][7][8].
- Recent advances (2024-2026) introduce adaptive reasoning via cross-turn estimation, federated GRPO for privacy-preserving training, multi-agent RL for self-evolving LLMs, and methods to address gradient starvation and runtime confidence calibration [8][9][10][11][12][13].
- Evaluation relies on benchmarks like GSM8K, MATH, and newer frameworks (SPARKLE, ConsensusBench) that assess plan-following and intermediate-step credit, with applications showing strong gains in math problem solving and adaptive test-time computation [14][15][16][17][18].

## Background
Reinforcement learning for LLM reasoning treats multi-step reasoning as a sequential decision-making process where models generate intermediate steps (chain-of-thought) and are optimized via reward signals [1]. This approach is needed to improve reasoning accuracy, reduce reliance on expensive human feedback, and enable adaptive, verifiable training through methods like GRPO and RLVR [1]. Foundational work relates RLHF, which aligns LLMs with human preferences via a reward model and PPO, to reasoning tasks where verifiable rewards (RLVR) can bypass reward models by using automatic correctness checks (e.g., calculators, compilers) [1][2]. The LLM acts as an agent that learns from rewards provided by the environment, with RLHF using human feedback to train a reward model then fine-tuning the LLM via PPO [2]. GRPO, a RLHF variant, groups similar samples and compares them, providing stable gradients and working with reward signals from any function, including verifiable rewards [2].

## Main Families of Approaches
The principal RL approaches for LLM reasoning include PPO-based RLHF, critic-free methods like GRPO and RLOO, Direct Preference Optimization (DPO), tree-search and test-time scaling strategies, and exploration-focused techniques such as ARM and competence-difficulty alignment [3][4][5][6][7][8]. A technical survey covers prominent RL algorithms such as PPO, Q-Learning, and Actor-Critic methods, discussing RLHF and RLAIF as foundational methods for aligning LLMs, and examining advanced strategies like DPO and GRPO for LLM alignment [3]. Tree-search-based reasoning views inference as instance-specific optimization rather than fixed decoding, covering methods like Best-of-N, sequential refinement, tree search, and evolution-style under a compute-allocation view [4]. Critic-free algorithms like GRPO and RLOO suffer from prompt-level advantage normalization leading to inaccurate advantage estimation and overfitting; REINFORCE++ introduces global advantage normalization to stabilize critic-free policy optimization [5]. Under memory and compute constraints, techniques like S-GRPO and T-SPMO improve benchmark accuracy and stability via parameter-efficient fine-tuning [6]. Exploration is addressed by ARM, which equilibrates confidence levels across correct responses using dynamic reward shaping to balance exploration and exploitation [7]. Competence-difficulty alignment strategy (CDAS) aligns model competence with problem difficulty to improve accuracy and efficiency by selecting training samples where the model's skill matches task complexity [8].

## Recent Advances (2024-2026)
Recent work focuses on adaptive reasoning to reduce unnecessary computation. The RACE (Reasoning Adaptation through Cross-Turn Estimation) method estimates when existing reasoning remains sufficient and when a new reasoning step is needed, reducing reasoning cost while maintaining or improving task performance [8]. Federated learning is extended to RL via Fed-GRPO, which leverages reward statistics naturally produced during GRPO training as the signal for federated updates, enabling collaborative reasoning training without sharing raw data [9]. Multi-agent reinforcement learning is used for self-evolving LLMs through SynCo, which synthesizes appropriate training data that matches the agent's current skill level via continual interaction and learning [10]. Scaling RL compute for self-improvement is demonstrated by MiMo-V2.6, which scales along dimensions including larger batches and higher throughput and asynchronous training [11]. Gradient starvation in off-policy learning is tackled by ReSPO, which replaces clipping in PPO with a smooth, two-branch objective to balance gradient updates [12]. Runtime confidence calibration for multi-agent foundation model coordination is provided by MARGIN, which learns model-specific confidence corrections from observed answer outcomes without retraining models [13].

## Evaluation, Benchmarks, and Applications
Evaluation of RL for LLM reasoning uses benchmarks like GSM8K and MATH, as well as newer fine-grained frameworks (SPARKLE, ConsensusBench) that assess plan-following, knowledge utilization, and intermediate-step credit [14][15][16][17][18]. ConsensusBench addresses the sparsity of final-answer rewards in GRPO-like algorithms by introducing outcome reward densifying to provide feedback on intermediate steps [15]. Adaptive reasoning for test-time compute allocation allows the model to learn to allocate its own reasoning effort by choosing, as the first token, modes like NoThink, Short, or Long, learned inside GRPO [16]. Offline RL methods like OREO (Offline REasoning Optimization) jointly learn a policy model and value function by optimizing the soft Bellman Equation, surpassing existing offline learning methods on multi-step reasoning benchmarks; a 1.5B model trained with OREO achieves 52.5% accuracy on the MATH dataset [17]. The SPARKLE framework evaluates LLMs along three axes: plan-following and execution, knowledge utilization, and subproblem decomposition, with SparkleRL-Stage 2 achieving notable scores on various benchmarks [18]. Applications show strong gains in math problem solving, with OREO achieving 52.5% on MATH, and adaptive test-time computation improving efficiency [17].

## Trends and open problems
Trends indicate a shift towards adaptive reasoning computation, federated and multi-agent RL for privacy-preserving and self-improving systems, and scaling RL compute along multiple dimensions [19][9][10][11]. Open problems include sparse reward limitations in complex reasoning trajectories, over-reliance on final answers, and the need for better verifiers and dense reward signals [15][17]. Gradient starvation remains a challenge in off-policy learning, requiring methods like ReSPO to balance gradient updates [12]. Runtime confidence calibration is essential for coordinating heterogeneous foundation models [13]. Exploration and sample efficiency continue to be active areas, with techniques like ARM and CDAS addressing entropy collapse and low sample efficiency [7]. Finally, the integration of RL with tool use and long-horizon reasoning presents both opportunities and challenges for future research.
